# Prakhar India — Manpower & Construction Website

Corporate and lead-generation website for Prakhar India, a trusted nationwide manpower supplier and construction contractor based in Mirzapur, Uttar Pradesh.

## Business Divisions

- **Manpower Supply** — Skilled, semi-skilled, and general workers for construction, industrial, infrastructure, and institutional projects
- **Building Construction** — Residential, commercial, institutional, and industrial construction
- **Government Contracts** — Eligible government and institutional contract execution

## Features

- Mobile-responsive design
- Bilingual (English / Hindi) with persistent toggle
- Lead capture forms with smart routing (manpower, construction, tender, worker)
- Worker registration (data stored separately from commercial leads)
- E-commerce booking system for labour and mistri with cart + payment flow
- Admin dashboard with lead management, filters, and CSV export
- Authentication with email login and phone/OTP login
- Project gallery with filters
- SEO metadata and JSON-LD structured data

## Tech Stack

- HTML5, CSS3, JavaScript (vanilla, no framework)
- localStorage for lead management and auth
- No build tools required — open in any browser

## How to View

Open `index.html` in any modern browser.
